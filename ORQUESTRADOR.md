# Venda.AI — ORQUESTRADOR

## Objetivo
Este arquivo define como o projeto deve ser organizado entre as áreas.

## Fonte única de verdade
Sempre consultar:
- /gestao/STATUS_MASTER.md
- /gestao/TAREFAS.md
- /gestao/BUGS.md
- /gestao/DECISOES.md

## Ordem de trabalho
1. QA identifica problemas.
2. DEV corrige problemas técnicos.
3. QA valida a correção.
4. PRODUTO decide prioridade.
5. CHANGELOG registra entrega.

## Regras
- Não criar novas funcionalidades enquanto houver bugs críticos.
- Não alterar arquitetura sem registrar decisão.
- Toda mudança deve ter motivo e resultado documentados.
- Priorizar funcionamento real antes de expansão.

## Papéis

### DEV
Responsável por:
- código;
- arquitetura;
- correções;
- manutenção.

### QA
Responsável por:
- testes;
- reprodução de bugs;
- validação de fluxos.

### PRODUTO
Responsável por:
- prioridades;
- experiência do usuário;
- decisões estratégicas.

### MARKETING
Responsável por:
- posicionamento;
- aquisição;
- vendas.
